# Описание структуры файлов данных

Данный набор данных основан на датасете MovieLens и содержит информацию о фильмах, пользователях, рейтингах, тегах, жанрах и профессиях. Все файлы представлены в текстовом формате (CSV/TSV) и используют разделители `|` или `,` в зависимости от файла.

## Список файлов

### 1. `genres.txt`
Список всех возможных жанров фильмов. Каждый жанр записан на отдельной строке.

**Пример содержания:**
Action
Adventure
Animation
...

### 2. `movies.csv`
Файл содержит информацию о фильмах.  
**Разделитель:** запятая `,` (поля с запятыми в названиях берутся в кавычки).  
**Поля:**

| Поле      | Описание                                                       |
|-----------|----------------------------------------------------------------|
| `movieId` | Уникальный идентификатор фильма                                |
| `title`   | Название фильма (может содержать год выпуска в скобках)       |
| `genres`  | Список жанров, разделённых символом `\|` (вертикальная черта) |

**Пример:**
1,Toy Story (1995),Adventure|Animation|Children|Comedy|Fantasy

### 3. `occupation.txt`
Список возможных профессий пользователей. Каждая профессия записана на отдельной строке.

**Пример содержания:**
administrator
artist
doctor
...

### 4. `ratings.csv`
Файл с оценками фильмов, поставленными пользователями.  
**Разделитель:** запятая `,`.  
**Поля:**

| Поле       | Описание                                                       |
|------------|----------------------------------------------------------------|
| `userId`   | Идентификатор пользователя                                     |
| `movieId`  | Идентификатор фильма                                           |
| `rating`   | Оценка (обычно от 0.5 до 5.0 с шагом 0.5)                     |
| `timestamp`| Время проставления оценки в формате Unix timestamp (секунды)   |

**Пример:**
1,1,4.0,964982703

### 5. `ratings_count.txt`
Файл содержит простую статистику по количеству оценок в наборе данных.  
**Содержимое:**  
- минимальная оценка и количество ее повторений
- максимальное оценка и количество ее повторений

**Пример содержания:**
минимальное число: 1, повторений 232
максимальное число: 120, повторений: 22

### 6. `sqlite.txt`
Файл содержит информацию о версии SQLite, использованной при обработке данных.  
**Пример содержания:**
Версия SQLite 3.35.5.

### 7. `tags.csv`
Файл с тегами, которые пользователи добавляли к фильмам.  
**Разделитель:** запятая `,`.  
**Поля:**

| Поле       | Описание                                                       |
|------------|----------------------------------------------------------------|
| `userId`   | Идентификатор пользователя                                     |
| `movieId`  | Идентификатор фильма                                           |
| `tag`      | Текст тега (может содержать запятые, но заключён в кавычки)    |
| `timestamp`| Время добавления тега в формате Unix timestamp (секунды)       |

**Пример:**
2,60756,funny,1445714994

### 8. `users.txt`
Файл с информацией о пользователях.  
**Разделитель:** вертикальная черта `|`.  
**Поля:**

| Поле          | Описание                                                       |
|---------------|----------------------------------------------------------------|
| `userId`      | Уникальный идентификатор пользователя                          |
| `name`        | Полное имя пользователя                                        |
| `email`       | Адрес электронной почты                                        |
| `gender`      | Пол (`male` или `female`)                                      |
| `birthdate`   | Дата рождения в формате `ГГГГ-ММ-ДД`                          |
| `occupation`  | Профессия (одно из значений из файла `occupation.txt`)         |

**Пример:**
1|Devonte Stamm|marianne.krajcik@bartoletti.com|male|2010-09-19|technician

## Дополнительная информация
- Все идентификаторы (`userId`, `movieId`) согласованы между файлами.
- Временные метки (`timestamp`) представлены в формате Unix (количество секунд с 01.01.1970).
- Жанры в `movies.csv` и теги в `tags.csv` могут содержать символы `|` или запятые, поэтому соответствующие поля обрабатываются с учётом экранирования.
